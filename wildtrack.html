Workflow

From Field to Report in 7 Steps

A fully auditable, traceable pipeline — every image, every decision, every output is logged and reversible.

1

Image Import

Transfer camera-trap images from SD cards. WildTrack registers metadata — date, time, camera ID, GPS — and never alters originals.

2

AI Batch Processing

MegaDetector v5 analyses each image offline — detecting species, humans, vehicles, livestock and blank frames with confidence scores.

3

Human Review

Authorised reviewers verify low-confidence detections, correct labels, assign multiple species and add field remarks — all tracked in audit log.

4

Species Library

Search and filter all verified images by species, date, camera, zone or review status. Export filtered sets anytime.

5

Occurrence Mapping

Generate carnivore occurrence maps, detection frequency maps and relative abundance indices from verified data and camera GPS coordinates.

6

Phase IV Reporting

Auto-generate Phase IV wildlife monitoring reports in PDF, Excel and CSV formats — templates customised with the Department during implementation.

System Capabilities

Every Requirement. Fully Met.

WildTrack DMS is purpose-built to address every functional and technical requirement of wildlife camera-trap data management for government forest departments.

✅
AI Image Annotation — All Categories

MegaDetector v5 detects and classifies wildlife species, humans, vehicles, livestock and blank/empty frames with confidence scoring per image.

✅
Batch Processing — Originals Protected

Full batch pipeline processes thousands of images per hour. Original files are read-only — never altered. Low-confidence detections auto-flagged for human review.

✅
Human Review — Full Workflow

Approve, correct or reject AI labels. Assign multiple species labels per image. Add field remarks. Every action timestamped in audit log with reviewer name.

✅
100% Offline — No Cloud Dependency

Zero internet required for any operation — import, processing, review, mapping or export. Network activity continuously monitored. Zero external transfers.

✅
Carnivore Mapping — 4 Map Types

Occurrence maps, detection frequency maps, relative abundance index maps and temporal activity charts showing time-of-day and seasonal patterns.

✅
Phase IV Report — Complete Output

Species summary tables, camera trap effort statistics, relative abundance indices, GIS maps embedded in report. Export in PDF, Excel and CSV.

✅
Departmental Computer Installation

Professional Windows .exe installer. Minimum and recommended hardware specs clearly stated. Runs on existing departmental hardware — no new purchase required.

✅
Access Period — Fully Covered

Complete access, support and maintenance included in lump-sum contract. Post-contract AMC available on request, priced on actual effort and expense basis.

✅
Online Training — 3 Dedicated Sessions

Session 1: Import & batch processing. Session 2: Review & correction workflow. Session 3: Mapping, reporting & export. Scheduled within 5 working days of request.

✅
Support & Escalation Matrix

Level 1: Support Executive — 24hr response. Level 2: Technical Lead — 12hr response. Level 3: CEO escalation — 24hr response. Critical issues: 4hr response.

✅
Data Security & Ownership

All images, annotations, maps and reports remain the Department's exclusive property. Zero outbound data transfer. Network monitoring logs every connection attempt.

✅
Local Storage & Backup

PostgreSQL database runs entirely on departmental hardware. Daily encrypted local backup. One-click restore. Written backup and recovery procedures at handover.
